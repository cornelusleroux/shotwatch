# Changelog

## v0.1.1 - 2025-11-27

### Added

- Subheaders for grouping related options on the configuration page.
- Changelog.

### Fixed

- Proper formatting for undefined/null session targets in CSV export.


## v0.1.0 - 2025-10-19

Initial public release with the following primary features:

- Amplitude-based microphone calibration.
- Configurable start/end buzzer (frequency, duration, and random delay).
- Session recording with configurable stop conditions (shot count, timeout, mark count, or a combination).
- Session details view with filterable event splits.
- Session history with CSV export.
- Embedded user guide.
